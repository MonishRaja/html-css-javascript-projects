!!! IMPORTANT !!!
Open the index.html using Live Server in VS Code and note down your machine's IP
Opening the file directly from your computer won't work

To get the API Key
1. Open this URL in your browser "https://restcountries.com/docs/countries"
2. Create an account
3. Click on the "API Keys" and click on "Create a new key"
4. In the "CORS allowed origins" add your computer's local IP
5. Wait 2-3 minutes and refresh your index.html
6. You should be successfully connected to REST API
